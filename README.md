# مقیمی V2Ray | Moghimi V2Ray

**MG_V2RAY** صفحه‌ی مقیمی V2Ray برای دسترسی به کانفیگ‌های V2Ray و ثبت درخواست اتصال اختصاصی است.

## ورود به سایت

[مشاهده‌ی سایت مقیمی V2Ray](https://moghimi-ir.github.io/MG_V2RAY/)

در سایت می‌توانی کانفیگ‌های منتشرشده را ببینی، متن اتصال را کپی کنی یا فایل آن را دریافت کنی. برای اتصال اختصاصی هم امکان ثبت درخواست وجود دارد.

**Moghimi V2Ray (MG_V2RAY)** provides a simple Persian-language page for browsing available V2Ray configurations, copying or downloading configuration files, and requesting a dedicated connection.
